# 《时痕拼图》白模机关交接表

对应 Unity 场景 `Assets/Whitebox/Map1_Whitebox_Flow_v2.unity` 和《时痕拼图》流程 V2 音频整合版。下表的对象名和坐标取自该场景，流程与验收条目供程序接入时使用。

## 在 Unity 里找机关

1. 打开 `Map1_Whitebox_Flow_v2`，在顶部菜单点 **Tools → 白模机关导航**。
2. 选择幕和机关，再点 **定位**。Unity 会在 Hierarchy 选中原对象，在 Scene 窗口标出它，并显示其路径和世界坐标。
3. 看到一个方块不知道用途时，先在 Scene 或 Hierarchy 选中它，再点 **查选中的方块**。如果是已记录机关的子件，会显示所属机关的说明。
4. 也可以在 Hierarchy 搜索下表的对象名，按 **3DWorld** 或 **2DWorld** 区分同名副本。机关需要跨世界同步时，绑定同一逻辑状态。

`X` 为推进里程，`Y` 为高度，`Z` 为左右。2D 舞台根节点在全局 `Z = 200`，两世界通行位置以 `X、Y` 及已有对应对象为准。表中坐标是对象枢轴，碰撞范围以 Inspector 和 Scene 为准。

## 白模上的方块各代表什么

| 看哪里 | 代表什么 | 接入时怎么用 |
| --- | --- | --- |
| `Grounds` 下的石台、楼梯、桥面本体 | 主要可走面 | 查本体的 Collider 或 Collider2D。用镶边和顶面的落差看路线。 |
| `*_Edge`、`*_Crown` 等细带 | 平台亮边、台冠等视觉构件 | 设置走路和落点时找平台本体。 |
| `Machines` 下的 `Lever`、`Wheel`、`Plate`、`Prism` 等 | 拉杆、手轮、踏板、棱镜的占位或组合 | 根据本表给原位置接输入、触发、反馈和共享状态。有组合占位时按所需子件拆分。 |
| `*_Frame`、`*_Lintel`、`*_Header` | 门框、门楣或出口提示 | 在该位置布置功能门，连接实际门板、阻挡碰撞和放行状态。 |
| `Sentinel`、`Boss` 或 `*_Staging` | 敌人外形和站位占位 | 用正式敌人预制体及行为替换或挂接。 |
| `*_Stance`、`*_Anchor`、`*_Position`、`*_Projection` | 站位、落点、投影或光束目标参照 | 用 Transform 定位；需要触发、阻挡或伤害判定时配置对应组件。 |
| `Storys` 下的 `Manuscript`、`Exhibit`、`Recording`、观测台 | 手稿、展品、录音或观景互动占位 | 依下表区分主线与可选内容。小方块也可能只是 `Plinth` 底座。 |
| `Decorations`、`Wayfinding*` | 建筑、外观和引导标记 | 名为掩体的 `Cover_Block`、`Laser_Cover` 等需检查对应碰撞或遮挡规则。 |

方块的颜色主要区分场景和材质。判断机关时先看对象名、所属世界和下表里的用途。

### 跨世界接入约定

- 已有 `Import3D` 对应关系的地面可作为切换落点基准。桥面悬空、缺对应点或落点有阻挡时，按策划拒绝切换并给反馈。
- 两个砍链输入都只放在 **3D**。2D 的检修台和观察台用于观察、对位和路线提示。
- 门、碎片与已完成的机关共用跨世界进度。方块提供站位和形状，机关执行、交互、敌人 AI 和音效仍需程序接入。
- 验收列是要跑的用例。音效编号沿用音频整合版。
