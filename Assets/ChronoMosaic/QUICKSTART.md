# 10 分钟看到相机效果

> **已经用 Unity 6000.0.83f1 + URP 17.0.4 实测跑通：30/30 项检查通过。**
> 现成项目在 `F:\日常处理\chrono-mosaic-unity`，用 Unity Hub 打开它 →
> 打开 `Assets/Scenes/CameraTest.unity` → 按 Play 就能试。
> 详细结果和发现的 bug 见 `VERIFICATION.md`。

不需要美术资源、不需要搭场景。生成一个白盒，按 Play。

---

## 0. 前置（只做一次）

1. 装 **Unity Hub**，再装 **Unity 2022.3 LTS** 或 **Unity 6**（默认模块即可）。
2. Unity Hub → New project → 模板选 **Universal 3D**（URP）。
   > 别选 Built-in 3D，后面的 shader 包不能用；相机本身不受影响。
3. 项目名随意，创建。

---

## 1. 拷文件（1 分钟）

把整个 `chrono-mosaic` 文件夹拖进 Unity 的 `Assets/` 目录。

等编译条转完，**Console 不能有红字**。
如果有红字，大概率是：Unity 版本太低（2021 以下）、或者文件被放到了 `Assets` 外面。

---

## 2. 生成场景（10 秒）

菜单栏 → **Tools → Chrono Mosaic → 1. 一键生成相机测试场景**

它会自动：
- 补齐 4 个维度 Layer（`Present3D_Only` / `RightWall_3D` / `Past2D_Only` / `Shared_Both`）
- 搭一个 20 × 24 m 的白盒：入口地板、深渊、平台、左墙、右墙、几根柱子
- 放下 2D 红毯桥（只在 2D 出现）
- 建好玩家、两个相机、脚下光圈、水彩遮罩、调试面板
- 把 `DimensionTransitionController` 的引用全部接好

场景视图会自动框住生成物。

> 想让它自动跑一遍并出报告：菜单 **Tools → Chrono Mosaic → 3. Play 模式自动测试**。
> 它会进 Play 模式、模拟切维度、检查相机与落点，最后退出并写出 `playtest-report.txt`。

---

## 3. 按 Play

操作：**WASD 移动，鼠标转视角，Q 切维度，空格跳，Esc 开关调试面板**。

左上角面板会实时显示：当前维度、`_DimBlend`、能不能切、会吸附到哪个 X。

---

## 4. 六个检查点

| # | 操作 | 预期 | 不对说明什么 |
|---|---|---|---|
| 1 | 鼠标左右移动 | 镜头绕着角色转，角色不动 | 相机没挂上，或 `target` 为空 |
| 2 | W 走向 z=8 的深渊 | 走到边缘停住，光圈变**青蓝** | 光圈没接 `probe`，或 `groundMask` 没勾地板层 |
| 3 | 站边缘按 Q | 米白遮罩从边缘收拢 → 切到侧视 → 遮罩散开 | 遮罩没接，或 `swapAt` 那帧遮罩不够不透明 |
| 4 | 2D 里按 D | 角色沿 +Z 向右走，脚下出现红毯 | 移动脚本没读 `Is2D`，或红毯 Layer 错 |
| 5 | 走到深渊中段（z 8~14）按 Q | **被拒绝**，光圈红闪 + 钝音 | `halfWidth` 太小，或光圈把红毯当成了 3D 地板 |
| 6 | 走过深渊（z > 14）按 Q | 切回 3D，人物站在原地板上 | 吸附逻辑错，看面板上的「吸附 X」是不是 0 附近 |

**第 5 条是这个系统最关键的行为**。如果它在深渊上方允你切回 3D，说明落点探测把 2D 红毯也算成了 3D 地面——检查 `groundMask` 里是不是误勾了 `Past2D_Only`。

---

## 5. 常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| 切 2D 后画面全黑 | 2D 相机旋转不是 `(0,-90,0)`，或 CullingMask 全空 | 选中 Camera2D 看 Inspector |
| 切 2D 被一面墙挡住 | 右墙没设 `RightWall_3D`，或 Layer 名字拼错 | Tools 菜单跑一次「2. 只检查维度 Layer」 |
| 按 Q 完全没反应 | `DimensionSystem` 没挂控制器，或 `player` 没拖 | 选中 DimensionSystem 看 Inspector |
| 角色在 2D 里不见了 | 角色在 Default 层，2D 相机不渲染它 | 把角色和光圈改到 `Shared_Both` |
| 镜头疯狂抖动/穿墙 | `collisionRadius` 太小，或相机出生在几何体内部 | 把半径调到 0.3，Play 前把相机移到空地 |
| 光圈一直红 | `probe` 指到了光圈自己而不是玩家 | `probe` 必须是玩家根节点 |

## 6. 想调手感，改这三个数

| 参数 | 位置 | 建议 |
|---|---|---|
| `distance` | Main Camera → ThirdPersonCameraRig | 3.2 ~ 3.8，走廊多就调小 |
| `autoAlignDelay` | 同上 | 1.5 ~ 2.0 秒，越小越"自动" |
| `orthoSize` | Camera2D → SideViewCamera2D | 6.0 ~ 6.5，决定 2D 画面能看多高 |

---

## 7. 接你们自己的角色

1. 删掉 `Tests/TestPlayerMotor.cs`（或从玩家身上移除）。
2. 把你们的移动脚本、攻击脚本拖进 `DimensionSystem → freezeDuringTransition`。
3. 玩家根节点保证挂着 `CharacterController` 或 `Rigidbody`，并拖到控制器对应字段。
4. 移动脚本里加一行：2D 时只允许沿 Z 移动（参考 `TestPlayerMotor` 的第 40 行）。

---

## 8. 什么时候算"相机做完了"

- [ ] 站在深渊边、平台边、楼梯上，光圈颜色都对
- [ ] 连续快速按 Q 十次，不卡死不残留
- [ ] 转场过程中镜头不抖、不闪、不穿墙
- [ ] 贴墙走一圈，镜头不卡进墙里
- [ ] 2D 里走到画面右边缘，能看到前方 2 m 的机关
- [ ] 闭眼再睁眼，能一眼说出"现在是 2D 还是 3D"

前五条是工程正确性，最后一条是这游戏能不能立住。

## 9. 七个机关：机关实验室

菜单 **Tools → Chrono Mosaic → 4. 生成机关实验室**，会生成 `Assets/Scenes/MechanismLab.unity`。
房间和相机测试场景一样，只是多了七个机关，分布在两块地板上：

| 位置 | 机关 | 上手怎么试 |
|---|---|---|
| 左前 (-7, 3) | 弹簧板 | 切 2D 站上去会被弹起来；3D 里踩上去没反应 |
| 前中 (-3.5, 3) | 过去残影 | 切 2D 按右键（RMB），刷出一个半透明人影 |
| 前中 (0.5 / 3.0, 2) | 双板门 | 两块板都压住门才开；松开一块立刻关 |
| 左右墙 (±9.5, 4.5) | **双墙齿轮** | 3D 拉 (-7, 0.8, 1.0) 的拉杆：主动轮转，但右墙从动轮隔 19 m 纹丝不动。切 2D，两轮投影相切成 3.30 = r₁+r₂，从动轮被带着转，(-7, 1.5, 7.5) 的门打开。切回 3D 又转不动了 |
| 后段 (-7, 15~21) | **十年树木** | 2D 里 Z=21 有玻璃隔断墙挡路 → 走到 (-7, 15) 按 E 推花洒 → 水流向树苗 → 玻璃碎 → 切回 3D，枯木桥从地里长出来可以踩 |
| 左后 (-7, 18) | 断链配重 | 切 2D 走近，**左键挥刀**砍断铁链，配重落下压住踏板 |
| 右后 (5, 18) | 聚光棱镜 | 3D 里光束点亮水晶；切 2D 光束消失 |

**注意：齿轮和树木是照策划案 §5.1 的规则搭的**，不是"摆个样子"：
齿轮的咬合由"两轮外切"算出来（3D 隔 19 m 必然不咬，2D 投影相切才咬），
树木的"玻璃碎 / 桥长出来"是同一个浇水动作的三个后果。

**为什么机关都排在 X = -7 线上？** 因为 2D 里 X 是锁死的，
你只能在“切换那一刻”站的那条 X 上活动。所以能上手试的机关必须和入口同一条线。
这也是关卡设计的硬约束：**同一条 2D 走廊上的机关，X 必须一致**，否则玩家永远够不着。

想让它自动跑一遍：菜单 **Tools → Chrono Mosaic → 5. 机关自动测试**，
它按 3D → 2D → 3D 的顺序把七个机关各测一次，结果写到 `mechtest-report.txt`。

## 10. 第一展厅白膜（整关）

菜单 **Tools → Chrono Mosaic → 6. 生成第一展厅白膜** → `Assets/Scenes/Hall01.unity`。
整关 48 m，坐标全部来自策划案 §5.1，走一遍大概两分钟：

| Z | 段落 | 怎么过 |
|---|---|---|
| 0 – 8 | 入口 | 出生点 |
| 8 – 14 | **红毯过坑** | 3D 是深渊 → Q 切 2D 走红毯。注意：**坑上方光圈是暗红的**，切不回 3D，要走到对面的平台 |
| 14 – 18 | 中间平台 | 3D 站得稳。走到 Z≈15.5 切 2D，按 **E** 推花洒 |
| 18 – 24 | **十年树木** | 花洒滑到树苗旁 → 浇水 → 2D 玻璃（Z=21）碎掉 → 切回 3D，踩着新长出的枯木桥走过去 |
| 24 – 36 | **双墙齿轮** | 3D 拉 Z=27 的拉杆：主动轮转，抬头看右墙从动轮**一动不动**（隔 19 m）→ Q 切 2D，两轮投影相切，转满一圈，Z=36 的大门升起 |
| 36 – 48 | **错位断桥** | 站在左断桥（X=-5）切 2D → 走到 Z=44（人物仍锁在 X=-5）→ 按 Q 切回 3D，**人物被吸到右断桥 X=+5** |

自动跑一遍：菜单 **7. 第一展厅自动测试**，30 项检查，结果写 `halltest-report.txt`。

### 白膜的三个已知取舍

1. **右断桥会挡 2D 镜头** —— 它在 +X，2D 相机从 +X 看过来正好在你前面。
   策划案的解法是三层构图 + RightWall 剔除，但断桥本身要能站人，白膜阶段先忍着。
2. **两只巡卫是占位方块**，没接 AI。
3. **门外那块 9 m 过渡平台是我加的** —— 策划案没写 6 m 门洞到左断桥之间那 2 m，不加会掉进虚空。

### 白膜能验证什么

- 四段机关的**空间关系**对不对（玩家能不能看懂"要去哪"）
- **视线引导**够不够（40 米长的走廊，第一眼能不能看见齿轮和断桥）
- 哪一段**走起来太远/太空**（白膜阶段最好改的就是距离）
